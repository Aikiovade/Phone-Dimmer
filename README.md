# Night Dimmer

Night Dimmer is an Android application that allows you to dim your screen brightness below the system minimum, protecting your eyes in dark environments.

## Features

- **Extreme Dimming**: Reduce screen brightness below the device's standard minimum.
- **Blue Light Filter**: Apply a warm tint to reduce eye strain before sleep.
- **Auto-Dimming**: Dynamically adjusts brightness based on ambient light using the device's light sensor.
- **Quick Settings Tile**: Conveniently toggle the dimmer directly from the Android notification shade.
- **Deep Black Theme**: A high-contrast dark mode for the settings interface to prevent glare.

## Installation

You can download the pre-compiled APK directly from this repository:
1. Download `NightDimmer.apk` from the root of this repository.
2. Open the APK on your Android device to install it.
3. You may need to grant the "Display over other apps" permission for the dimmer overlay to work.

## Build from Source

1. Clone the repository.
2. Open the project in Android Studio.
3. Build and run the app on your device or emulator.
